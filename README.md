# CarCal
End-to-end AI system for vehicle damage assessment and repair cost estimation, designed to take real-world accident images as input and return a structured, explainable cost estimate as output. The solution is built around a modular client–API–engine architecture: a web client handles user interaction and image upload, an API layer validates requests, orchestrates the workflow, and enforces security and logging, and an internal AI engine performs the core inference pipeline (damage detection, severity assessment, and cost estimation). The modular separation improves maintainability and scalability, enabling independent development, testing, and deployment of each component, while also supporting future extensions such as multi-image fusion, vehicle metadata integration (e.g., make/model/year), uncertainty-aware price ranges, and detailed cost breakdowns (parts, labor, and paint).
